My Dev Tools Vandalism

I used browser developer tools to temporarily "vandalize" the Dell website. Below is a screenshot showing my changes. These edits only appeared on my computer and did not affect the actual website.

What I "Vandalized" - dell.com

Below is a description of the changes I made to the Dell website using browser developer tools:

  • I modified the search prompt on the landing page by changing the text and the font.
  • The only CSS property I modified was font-family changing it to Brush Script MT, which is completely out of place on the Dell website.
  • Corporate sites often ask how they can help, but can become difficult to navigate so I thought "How can I make your life miserable today" was mildly humorous.
  • I had difficulty finding a font that actually changed the text. After a quick Google search I came across one that was completely out of character for the Dell website and went with that.
  • Familiarity as I worked at Dell for several years and know the brand and design principles.
  • It was easy to understand how the HTML and CSS worked together to make the changes I made. I have work experience with html and css so I'm familiar with the properties and selectors, although there are now additions since I was hands on with css.
  • I hadn't used devtools to modify a page on the fly, so I see how it can be a useful tool to test things out.
